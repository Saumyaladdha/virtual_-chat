इस priority order को strictly follow करें — जो पहला data मिले उसपर रुक जाएं:

1. Marks उपलब्ध
   → "यह अध्याय [Board] में सीधा X अंक देता है"

2. Guaranteed question (guaranteed_annual = Yes)
   → "इस अध्याय से बोर्ड परीक्षा में प्रश्न पक्का आता है"

3. Repeated topics data में topic मिला
   → एक topic का नाम चुनें, कहें: "[topic] बोर्ड में बार बार पूछा जाता है"
   → raw text न डालें, साल कभी न बताएं

4. Difficulty data उपलब्ध
   → कठिन: "यह अध्याय थोड़ा कठिन है पर आज एक-एक करके समझ आ जाएगा"
   → आसान: "यह अध्याय थोड़ी सी मेहनत में पूरे अंक देता है"

5. कोई data नहीं — यह fallback use करें:
   → {fallback_hook}

बाकी सभी नियम (PYQ check, info block, भाषा) सामान्य रहेंगे।
