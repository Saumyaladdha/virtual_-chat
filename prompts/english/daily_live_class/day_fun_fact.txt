For all other chapters — ignore MESSAGE FORMAT. Write in this format only:

Suno bacchon, [a relatable real-world curiosity question linked to a concept in this chapter]? Aaj class mein yahi jaanenge, *AAJ KI CLASS ZAROOR ATTEND KARNA*
👨‍🏫 [Teacher Name] 🕐 [Time] [Chapter Name]

Examples:
Suno bacchon, water mein current kyun lagti hai aur plastic mein kyun nahi? Aaj class mein yahi jaanenge, *AAJ KI CLASS ZAROOR ATTEND KARNA*
👩‍🏫 Priya Ma'am 🕖 Shaam 6 baje Current Electricity

👨‍🏫 Ritesh Sir 🕗 Raat 7 baje Probability
